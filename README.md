# ReconcileAI

An explainable payment and settlement reconciliation agent built for Razorpay's **AI Finance Controller** track.

## Problem

Finance teams manually compare orders, gateway payments, settlements, and bank credits. ReconcileAI closes this loop across a batch, reports measured accuracy, and sends uncertain cases to human review instead of silently guessing.

## Current milestone

- Deterministic, reproducible synthetic finance data
- More than 50 records across four sources
- Realistic missing, duplicate, delayed, refunded, fee-mismatch, and amount-mismatch cases
- Labelled ground truth for honest evaluation
- Matching engine with confidence, explanations, and unresolved exceptions
- Precision, recall, F1, false-positive, and false-negative reporting

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/generate_data.py
python scripts/evaluate.py
python -m pytest
python -m uvicorn backend.app.main:app --reload
```

API documentation is available at `http://127.0.0.1:8000/docs`.

## Safety principles

- Rules perform exact and financial calculations.
- AI will investigate ambiguity, not alter source financial records.
- Medium-confidence cases require approval.
- Low-confidence cases remain unresolved.
- Every recommendation includes evidence and an audit event.

## Planned architecture

CSV sources -> validation -> deterministic matcher -> AI exception investigator -> policy guardrails -> human approval -> reports and audit log.

## Dataset

All data in `data/sample/` is synthetic and generated with a fixed seed. `data/ground_truth/` is used only for evaluation, never for matching.
